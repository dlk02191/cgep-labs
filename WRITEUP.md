## Chain of Custody

This implementation demonstrates four properties of an audit-grade evidence chain.

| Chain Property | Artifact That Proves It |
|----------------|-------------------------|
| Integrity | The `.sha256` sidecar file and `scripts/verify-evidence.sh` recompute the SHA-256 hash of the evidence bundle. Verification succeeds for the original bundle and fails after the tamper demonstration. |
| Authenticity | The `.sig.bundle` generated by Cosign keyless signing is verified by `scripts/verify-evidence.sh`, proving the bundle was signed through Sigstore using GitHub OIDC. |
| Preservation | The evidence bundle, `.sha256`, `.sig.bundle`, and `receipt.json` are stored in the S3 Object Lock evidence vault created in Lab 2.5, preserving the evidence during the configured retention period. |
| Traceability | `receipt.json` records the GitHub Actions run ID, vault name, object key, object VersionId, SHA-256 digest, and commit SHA, allowing the exact evidence bundle to be traced back to the workflow run that produced it. |
